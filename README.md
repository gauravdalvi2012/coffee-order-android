# Coffee Order

Android application for creating and managing coffee orders.

## Overview

Coffee Order is a small Android application that explores a simple coffee ordering workflow.

The project focuses on Android UI development, user input handling, and managing order information within a straightforward application.

## Features

* Create coffee orders
* Enter and configure order details
* Review order information
* Simple Android user interface

## Architecture

User
↓
Android UI
↓
Order Input
↓
Order Data
↓
Order Summary

## Tech Stack

* Java
* Android

## What I Learned

* Building Android user interfaces
* Handling user input and form interactions
* Managing application state
* Designing a simple ordering workflow
